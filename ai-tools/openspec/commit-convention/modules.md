# Commit 模組標籤對應

commit 主旨 `Issue #<號碼> [<模組>] <描述>` 中的 `<模組>` 取自下表，**縮寫**或**模組名稱**皆可（如 `[WF]` 或 `[電子簽核]`）。縮寫同時是程式碼路徑與資料表使用的前綴（如 `app/Services/WF/`、`wf_workflow`）。

新增模組時同步更新本表，`commit-msg` hook 以此檔為驗證來源。
